# Quick

Прозрачное окно поверх экрана для Windows. По горячей клавише программа делает скриншот, отправляет его в Gemini и показывает ответ прямо поверх того, что открыто на экране.

## Что нужно

- Windows 10 или 11
- Свой ключ Gemini API (бесплатный, из Google AI Studio)
- Лицензионный код
- Интернет (без сети программа не работает)

## Установка

1. Скачай `Quick.exe` и `Quick.exe.sig` из раздела **Releases**. Оба файла должны лежать в одной папке.
2. В этой же папке создай текстовый файл `key.txt` и впиши в него свой ключ Gemini. Если ключей несколько, пиши по одному на строке.
3. Запусти `Quick.exe` двойным кликом.
4. При первом запуске появится окно активации. Введи лицензионный код. Он сохранится, повторно вводить не нужно.

Если Windows или антивирус ругается на неизвестную программу, это нормально для программ без платной подписи издателя. Файл можно проверить: рядом лежит `Quick.exe.sig`, и без него программа не запустится.

## Как получить ключ Gemini

1. Зайди в [Google AI Studio](https://aistudio.google.com) под своим аккаунтом Google.
2. Нажми **Get API key** и создай ключ.
3. Скопируй ключ в `key.txt`.

Ключ у каждого свой, и лимиты у Google тоже свои на каждый проект. Хочешь больше запросов в день: создай ещё один ключ **в отдельном проекте** и впиши его второй строкой в `key.txt`. Два ключа из одного проекта делят одну квоту.

Не показывай свой ключ другим людям и не выкладывай его в интернет.

## Горячие клавиши

Все сочетания начинаются с `Ctrl+Alt`. Работают на любой раскладке, но если что-то не срабатывает, переключись на английскую.

### Основные

| Клавиша | Действие |
|---------|----------|
| Space | добавить скриншот в стопку (до 8 штук) |
| R | отправить стопку; если она пуста, снять экран и отправить |
| X | убрать последний скриншот из стопки |
| Q | скрыть или показать окно |
| End | выход |
| H | справка (две страницы) |

### Ответ

| Клавиша | Действие |
|---------|----------|
| W / S | строка вверх / вниз |
| A / D | символ влево / вправо |
| E | поставить метку (выделение от метки до курсора) |
| C | копировать: выделенное, а без метки весь ответ |
| F | уточнить ответ: меню на 10 секунд, потом цифра 1-5 (см. ниже) |
| Z | прошлые ответы (последние 10), назад |
| Shift+Z | прошлые ответы, вперёд |

### Настройки

| Клавиша | Действие |
|---------|----------|
| M | сменить модель |
| K | сменить ключ Gemini |
| P | режим ответа (по кругу) |
| T | светлая или тёмная тема |
| V | режим вида: двигать и менять размер окна |

### Режим вида (V)

Пока он включён, работают отдельные клавиши:

| Клавиша | Действие |
|---------|----------|
| Стрелки | двигать окно |
| `=` и `-` | прозрачность |
| PgUp / PgDn | размер окна |
| `]` и `[` | размер шрифта |
| `0` | сбросить вид |
| Esc или V | выйти из режима |

## Режимы ответа (P)

| Режим | Как отвечает |
|-------|--------------|
| база | тесты: номер, буква и текст варианта; расчёты с одной строкой пояснения |
| Excel | формулы с адресом клетки, разделитель аргументов `;` |
| код | только готовый код без объяснений |
| математика | кратко по шагам, в конце «Ответ: ...» |
| только ответ | только итог: число, слово или вариант |

## Уточнить ответ (F)

Если ответ непонятен или вызывает сомнения, не нужно снимать экран заново. Нажми `Ctrl+Alt+F`: в окне появится меню на 10 секунд. Нажми цифру 1-5, и программа задаст нейросети дополнительный вопрос по тому же скриншоту (или стопке скриншотов) и тому же разговору. Если за 10 секунд цифру не нажать, меню закроется само. Повторное `F` тоже закрывает меню.

| Цифра | Что делает |
|-------|-----------|
| 1 — подробнее | просит объяснить подробнее |
| 2 — проще | просит объяснить проще |
| 3 — перепроверь | просит перепроверить ответ по условию на скриншоте и, если была ошибка, исправить |
| 4 — только ответ | просит дать только итог, без пояснений |
| 5 | в режиме Excel «в русском Excel»: перепишет формулы под русский Excel (СУММ, ЕСЛИ, разделитель `;`); в остальных режимах «чего не хватает»: подскажет, что мешает решить, например задание обрезано на скриншоте |

Важно знать:

- Меню работает только после того, как уже получен ответ (после `R`). Иначе будет написано «Сначала получи ответ (R)».
- Каждое уточнение это отдельный запрос к нейросети, он уменьшает остаток запросов в углу окна так же, как обычный.
- Пока идёт ответ, открыть меню нельзя.

## Цифры в углу окна

Три цифры справа сверху: **модель·ключ**, остаток запросов **в минуту**, остаток запросов **в день**. Для каждой пары «ключ + модель» они считаются отдельно. Суточный счёт сбрасывается по времени Лос-Анджелеса, как у Google. Если перед ответом стоит `~`, значит, ответила запасная (вторая) модель.

## Частые проблемы

| Что пишет | Что делать |
|-----------|-----------|
| Рядом с Quick.exe нет файла key.txt | положи `key.txt` в одну папку с `Quick.exe` |
| Ошибка 401 / Ключ не подходит | ключ введён с ошибкой или отозван: проверь `key.txt`, нажми K, чтобы переключиться на другой ключ |
| Лимит Google | нажми K (другой ключ) или M (другая модель) или подожди |
| Код занят другим компьютером | код привязан к одному компьютеру: напиши автору, он сбросит привязку |
| Код уже запущен в другом окне | закрой программу на другом компьютере (Ctrl+Alt+End), код освободится сразу; если она закрылась аварийно или пропал свет, подожди 10 минут |
| Срок кода закончился | нужен новый код |
| Нет сети или сервер недоступен | проверь интернет: без сети программа закрывается |

## Правила

- Один код работает на одном компьютере (если автор не выдал иначе).
- Срок кода отсчитывается от первой активации.
- Код нельзя передавать другим людям: автор может его отозвать.
